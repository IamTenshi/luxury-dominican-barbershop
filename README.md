# Luxury Dominican Barbershop

Website for **Luxury Dominican Barbershop** — 4325 Atlanta Hwy Suite 12, Loganville, GA 30052.

## Stack

- [Astro](https://astro.build) 7.3 (static build)
- [Tailwind CSS](https://tailwindcss.com) 4.3 (CSS-first config)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output goes to `dist/` — ready to deploy on Vercel, Netlify, or any static host.

## Content

All site content lives in `src/data/site.ts`. Photos are in `public/images/`.
